# Запуск и размещение

1. Создайте MySQL/MariaDB базу и пользователя с доступом к ней. Скопируйте aulieata-secrets.example.php в aulieata-secrets.php вне public/. Заполните db_host, db_name, db_user, db_pass, base_url и ключ Gemini.
2. Для новой установки задайте независимые случайные webhook_secret и encryption_key. При обновлении сохраняйте существующие значения: смена ключа сделает подключённые токены недоступными. В прежней установке без encryption_key используется прежний webhook_secret.
3. Выполните php tools/migrate.php из корня. Команда создаёт отсутствующие базовые и прикладные таблицы через CREATE TABLE IF NOT EXISTS, не удаляет записи. Перед обновлением рабочей базы сделайте резервную копию.
4. Корень сайта — public/. В Plesk разместите содержимое public/ в httpdocs/, а aulieata-secrets.php уровнем выше. Никакие конфиги, дампы и архивы не должны находиться в httpdocs/.
5. Укажите HTTPS base_url вашего сайта. Webhook Telegram, приглашения сотрудников и персональные ссылки строятся из этой настройки. При смене домена переподключите бота в настройках.
6. Войдите через login.php, задайте сферу, импортируйте каталог и проверьте наличие. В «Операционный центр → Подготовка бизнеса» настройте приём заказов, запись и напоминания. Для расписания нужны услуги, длительность, ресурсы и рабочие часы.
7. Запускайте php /absolute/path/public/cron.php каждую минуту. Обработчик защищён от параллельного запуска; дневные задания выполняются по своему расписанию. На действующем хостинге эта частота настроена 18 октября 2026 года.

PHP 8.1+: PDO MySQL, mbstring, cURL, OpenSSL; для фотографий GD. На Windows cURL нужен актуальный доверенный CA bundle. Проверки выполнялись с PHP 8.3 и MariaDB 11.4; рабочий веб-хостинг использует PHP 8.1. Конфиг также можно задать переменной окружения AULIEATA_CONFIG (абсолютный приватный путь).

## Изолированные проверки

Создайте отдельную локальную базу с именем itu_test_operations и отдельный конфиг. Интеграционные тесты откажутся работать с базой без префикса itu_test_ или с нелокальным DB-хостом. Тесты добавляют только искусственные данные в этой базе.

Пример PowerShell:

~~~powershell
$env:AULIEATA_CONFIG='C:/private/itu-test-config.php'
php tools/migrate.php
npm ci
npm test
php tests/integration.php
php tests/instagram.php
~~~

Для HTTP-проверки укажите в тестовом конфиге base_url=http://127.0.0.1:8187, запустите php -S 127.0.0.1:8187 -t public и в другом терминале выполните php tests/http.php. HTTP-тест создаёт локальную тестовую кофейню и проверяет вход, роли, отзывы, персональные ссылки и фото. Использовать этот сервер в интернете нельзя.

## Хранение и восстановление

Храните отдельно конфиг и ключ шифрования, копии базы, каталог aulieata-media/ вне public/ с фотографиями обслуживания. Перед развёртыванием копируйте действующие файлы и базу. Для отката возвращайте прежние файлы и конфиг; новая схема добавляет таблицы, старые данные остаются. Восстановление дампа поверх текущей базы требует учёта записей, появившихся после копии.

Не коммитьте конфиги, пользовательские данные, клиентские сообщения, фото и дампы. Автоматическое развёртывание из GitHub не настроено.

## Тестовое подключение Instagram

Войдите как владелец и откройте «Подключения → Instagram». Вставьте маркер из Meta Developers для профессионального аккаунта, допущенного к тестированию вашего приложения. Сохранение проверяет профиль и, если доступно, текущий лимит публикаций. Используется Instagram Login API; токен передаётся в заголовке Authorization только серверу Instagram.

Сервер сохраняет токен зашифрованным в отдельной таблице, созданной миграцией. Сохраняйте прежний ключ шифрования при обновлениях. Маркер можно заменить после истечения/отзыва; автоматического продления нет. Отключение удаляет сохранённый токен рабочего пространства, а разрешения приложения отдельно отзываются в настройках Instagram.

Модуль пока не публикует материалы и не реализует OAuth для сторонних компаний. Проверка лимита не проверяет разрешение на отправку поста. Тест instagram.php использует подставные ответы провайдера и не обращается к Instagram.
