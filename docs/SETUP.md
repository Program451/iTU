# Запуск и размещение

1. Создайте отдельную базу MySQL/MariaDB и пользователя с доступом к ней. Для новой базы импортируйте `database/schema.sql`. Это минимальная базовая схема, восстановленная по запросам приложения, а не дамп существующего сервера. Не применяйте её как миграцию к рабочей базе без проверки.
2. Скопируйте `aulieata-secrets.example.php` в `aulieata-secrets.php` в корне проекта. Укажите `db_name`, `db_user`, `db_pass`, ключ Gemini и независимые случайные значения `webhook_secret` и `encryption_key`. Не меняйте ключ шифрования после сохранения подключений ботов без отдельной миграции.
3. Настройте корень сайта на каталог `public/`. В Plesk можно загрузить содержимое `public/` в `httpdocs/`, а рабочий конфиг поместить уровнем выше `httpdocs/`. Сам конфиг, документация и база не должны раздаваться веб-сервером.
4. Откройте `login.php`, зарегистрируйте бизнес и войдите. Остальные таблицы создаёт приложение при инициализации кабинета. Затем задайте сферу бизнеса и импортируйте проверенные позиции. Не выдавайте демонстрационные данные за реальные.
5. Telegram подключается в настройках отдельного бизнеса. Для другого домена сначала замените ссылки на `https://itudron.ru/` в исходниках: текущие webhook, приглашения сотрудников и ссылки портала привязаны к этому домену. Используйте HTTPS.
6. Существующий фоновый обработчик запускается из CLI: `php /absolute/path/public/cron.php`. На текущем хостинге был настроен запуск раз в час. Новая очередь напоминаний и её частота ещё требуют проверки; репозиторий не меняет расписание хостинга автоматически.

Для локального изучения интерфейса можно использовать `php -S 127.0.0.1:8080 -t public` после настройки отдельной тестовой базы. Это не сервер для публикации в интернете. До завершения проверки нового модуля operations не заменяйте им рабочую установку автоматически.

## Что хранить отдельно

- Рабочий `aulieata-secrets.php` и резервную копию ключа шифрования.
- Резервные копии базы, содержащие аккаунты, токены подключений и сообщения.
- Каталог `aulieata-media/` вне корня сайта для фотографий из новых карточек обслуживания.

## Проверка исходников

```sh
npm ci
npm test
php -l public/index.php
php -l public/telegram.php
```

В репозитории нет автоматического развёртывания и нет действующих секретов.
