# iTu / AulieAta AI

Веб-приложение для малого бизнеса: каталог, клиенты, Telegram-помощник, инструменты с ИИ и управление повседневной работой. PHP, MySQL/MariaDB, JavaScript. Интерфейс сохраняет текущее название AulieAta AI; окончательный ребрендинг ещё не выбран.

## Статус исходников

18 октября 2026 года расширение operations доработано, проверено и опубликовано на https://itudron.ru. Перед размещением сохранены копии файлов, базы и конфигурации. Существующие аккаунты, каталог и подключения сохранены.

Теперь доступны заказы с резервом и списанием партий, состав блюд, расписание с длительностью и перерывами, переносы и напоминания, обращения к сотруднику, роли команды, импорт с просмотром изменений и отменой, помощник владельца, подбор по бюджету, сравнение поставщиков, передача смены, карточки обслуживания и отзывы по QR.

В настройках также доступно тестовое подключение профессионального Instagram-аккаунта по маркеру Meta Developers: зашифрованное хранение, проверка аккаунта, замена маркера и отключение. Управлять подключением может только владелец. Публикация постов, расписание, генерация изображений и OAuth для сторонних бизнесов пока не реализованы.

Проверки: 26 сценариев на изолированной MariaDB, включая одновременные запросы; HTTP-проверки входа, прав, отзывов и закрытых ссылок; реальные запросы Gemini для заказа, плана владельца, бюджета, прайса, смены и расшифровки голоса. На рабочем сайте проверены вход, загрузка данных, ответ бота в предпросмотре и применение/отмена плана. Подробности и границы проверки — в [статусе разработки](docs/DEVELOPMENT-STATUS.md).

## Состав репозитория

- `public/` — PHP-приложение и используемые JavaScript-файлы; корень сайта должен указывать сюда.
- `database/schema.sql` — базовые таблицы для новой базы, без пользовательских данных.
- `aulieata-secrets.example.php` — пустой шаблон настроек; рабочие ключи хранятся вне корня сайта.
- `tests/` — проверки синтаксиса, CSV, каталогов, бизнес-сценариев, конкурентных запросов и HTTP.
- `docs/` — запуск, ограничения и результаты проверки.
- `docs/presentation/` — презентация проекта в PDF.

Пароли, API-ключи, выгрузки пользовательской базы, сообщения клиентов, записи голоса, локальные резервные копии и другие проекты из рабочей папки в репозиторий не включены.

## Запуск

См. [инструкцию по запуску](docs/SETUP.md). Для PHP нужны PDO MySQL, mbstring, cURL и OpenSSL; для новых функций с фотографиями — GD. Сервер с HTTPS нужен для Telegram webhook и записи голоса в браузере. Исходники рассчитаны на синтаксис PHP 8.1+, локальная проверка выполнялась PHP 8.3.

Автоматическое развёртывание из GitHub не настроено. Публикация на сайте выполнена отдельно через хостинг.

## Проверки

```sh
npm ci
npm test
```

Node.js используется для проверок разработки; основной сервер приложения работает на PHP. Интеграционные и HTTP-проверки запускаются отдельно на локальной базе с именем itu_test_*; команды приведены в инструкции.

## Внешние зависимости

Google Gemini используется для ИИ и голоса, Telegram Bot API — для бота. WhatsApp Cloud API, Google Calendar OAuth, 2GIS/Google Maps, автоматическая синхронизация Kaspi/1С и платежи в этой версии не подключены. Наборы каталога содержат демонстрационные данные, а не реальные цены и остатки бизнеса.
