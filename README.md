# iTu / AulieAta AI

Веб-приложение для малого бизнеса: каталог, клиенты, Telegram-помощник, инструменты с ИИ и управление повседневной работой. PHP, MySQL/MariaDB, JavaScript. Интерфейс сохраняет текущее название AulieAta AI; окончательный ребрендинг ещё не выбран.

## Статус исходников

Сохранён текущий рабочий код на момент остановки разработки 17 октября 2026 года, **включая незавершённое расширение operations**. Это не точная копия последней версии на хостинге. Новое расширение прошло проверку синтаксиса, но ещё не прошло полную проверку сценариев и не было опубликовано на рабочем сайте.

В последней опубликованной версии ранее проверялись каталог и отраслевые примеры, импорт Excel/CSV, подключение Telegram для отдельных бизнесов, текстовые и голосовые ответы, база знаний, черновики акций и ежедневные автоматизации. Отдельные внешние интеграции требуют подключения.

Новые исходники содержат заказы и резервирование партий, состав блюд, расписания с длительностью, передачу разговора сотруднику, роли команды, обновление каталога из импорта, помощника владельца, подбор по бюджету, поставщиков, передачу смены, историю обслуживания и отзывы по QR. Их готовность и оставшиеся проверки описаны в [статусе разработки](docs/DEVELOPMENT-STATUS.md).

## Состав репозитория

- `public/` — PHP-приложение и используемые JavaScript-файлы; корень сайта должен указывать сюда.
- `database/schema.sql` — базовые таблицы для новой базы, без пользовательских данных.
- `aulieata-secrets.example.php` — пустой шаблон настроек; рабочие ключи хранятся вне корня сайта.
- `tests/` — проверки синтаксиса, CSV и демонстрационных каталогов.
- `docs/` — запуск, ограничения и статус незавершённой работы.
- `docs/presentation/` — презентация проекта в PDF.

Пароли, API-ключи, выгрузки пользовательской базы, сообщения клиентов, записи голоса, локальные резервные копии и другие проекты из рабочей папки в репозиторий не включены.

## Запуск

См. [инструкцию по запуску](docs/SETUP.md). Для PHP нужны PDO MySQL, mbstring, cURL и OpenSSL; для новых функций с фотографиями — GD. Сервер с HTTPS нужен для Telegram webhook и записи голоса в браузере. Исходники рассчитаны на синтаксис PHP 8.1+, локальная проверка выполнялась PHP 8.3.

Разработка приостановлена по просьбе владельца. Загрузка в GitHub не разворачивает изменения на рабочем сайте.

## Проверки

```sh
npm ci
npm test
```

Node.js используется для проверок разработки; основной сервер приложения работает на PHP. Эти проверки не заменяют проверку заказов, конкурентных запросов, прав сотрудников и доставки сообщений с реальной базой.

## Внешние зависимости

Google Gemini используется для ИИ и голоса, Telegram Bot API — для бота. WhatsApp Cloud API, Google Calendar OAuth, 2GIS/Google Maps, автоматическая синхронизация Kaspi/1С и платежи в этой версии не подключены. Наборы каталога содержат демонстрационные данные, а не реальные цены и остатки бизнеса.
